MinimalNotes Pro

MinimalNotes Pro is a lightweight, secure desktop note-taking and wiki application designed for speed, structure, and simplicity.

Features

Local Storage: Keep your notes, wikis, and reminders stored safely on your machine.

Clean UI: Responsive webview interface powered by dedicated local application services.

System Tray Integration: Quick access and background functionality.

Automated Backups: Automatic creation of SQLite database backups (minimal_wiki_backup.db).

Directory Structure & User Data

MinimalNotes Pro separates application binaries from user data to ensure security and compliance with Windows permissions:

Application Binaries (C:\Program Files\MinimalNotesPro): Read-only core files, UI web assets, and runtime dependencies.

User Data Directory (%LOCALAPPDATA%\MinimalNotesPro): Stores writable user files, including database (minimal_wiki.db), settings (settings.json), and backups.
